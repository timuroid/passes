# Product

Бизнес-описание сервиса оформления пропусков для ЗТЗ: назначение, роли, пользовательские сценарии и ограничения.

## Назначение

Водитель без регистрации передаёт номер автомобиля и обязательный номер телефона через публичную страницу киоска. Логист получает обращения в рабочем списке и обрабатывает их. Администратор управляет рабочим списком, учётными записями и настройками водительской страницы.

## Роли и основные сценарии

- **Водитель:** выбирает язык, вводит номер автомобиля и телефон на экранной клавиатуре, отправляет обращение и получает подтверждение.
- **Логист:** входит в кабинет, ищет и фильтрует транспорт, связывается с водителем, скрывает обработанные записи и при необходимости возвращает их.
- **Администратор:** выполняет действия логиста, создаёт и отключает пользователей, меняет пароли, выбирает тему водительского киоска и редактирует основной текст.

Язык выбирается водителем на публичной странице. В админ-панели отдельного выбора языка текста нет.
